## Git Commands

# 1️⃣ Initialize a new Git repository (if not already done)
git init

# 2️⃣ Add a remote origin (replace URL with your repo's URL)
git remote add origin https://github.com/your-username/your-repo-name.git

# 3️⃣ Stage all changes
git add .

# 4️⃣ Commit with a message
git commit -m "Initial commit"

# 5️⃣ Push code to the main branch
git branch -M main
git push -u origin main

# 6️⃣ Create a new branch for feature development
git checkout -b feature/your-feature-name

# 7️⃣ Push the new branch to GitHub
git push -u origin feature/your-feature-name
